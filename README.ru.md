## Возможности

- **Общие сведения.** DiskTide измеряет каждый каталог четырьмя способами: логический размер, занятые блоки, уникальные байты на диске после исключения жёстких ссылок и число файлов. Разреженные файлы, жёсткие ссылки и множество мелких файлов видны такими, какие они есть. Всё, что не удалось просканировать (другие файловые системы, псевдомонтирования, исключённые пути и каталоги без доступа), отражается в полноте охвата, а не пропадает незаметно.
  - Шесть цветовых тем; одна использует 16 цветов вашего терминала. Поддерживается мышь. Настройки и данные хранятся в стандартных каталогах XDG.

- **Обзор (Explorer).** Отсортированное дерево файлов рядом с круговой диаграммой (Sunburst), картой блоков (Treemap) или панелью подробностей. `t` переключает метрику размера, `g` меняет форму круговой диаграммы (tiles, disc, fill), `d` показывает изменения между двумя сохранёнными снимками. По умолчанию используются два последних.

- **Мониторинг.** По расписанию (по умолчанию каждые 6 часов) снимает состояние каталога и показывает его рост: график динамики, treemap различий, диаграмму роста sunburst и тепловую карту повторяющегося роста. Снимки можно закреплять; срок хранения постепенно удаляет старые, а заданные пороги вызывают оповещения.
  - Фоновой службы нет. Сканирование выполняется только во время сбора данных в сеансе TUI (`S` в центре мониторинга или автозапуск) либо пока работает `disktide watch`.

- **Очистка.** Находит освобождаемые артефакты сборки и кэша с помощью шести наборов правил (Python, Node, Rust, общие, IDE, контейнеры). Перед перемещением вы проверяете план. Файлы отправляются в системную корзину или каталог карантина; план можно отменить. Безвозвратное удаление — отдельный шаг с подтверждением вводом текста.

Сканирование читает только метаданные: DiskTide никогда не открывает содержимое файлов. Небольшое необязательное расширение C ускоряет многопоточное сканирование примерно вдвое.

## Установка

Python 3.10–3.14, Linux или macOS, пять зависимостей времени выполнения.

Команды установки из PyPI загружают оригинальную англоязычную версию. Для русской локализации выполните в корне рабочей копии с переводом `uv sync --locked`, затем `DISKTIDE_LANG=ru uv run disktide`. Для английского интерфейса задайте `DISKTIDE_LANG=en`. Без переменной язык определяется по настройкам локали.

**Через uv** (рекомендуется; [почему uv?](docs/why-uv.ru.md)):

```bash
uv tool install disktide   # изолированное окружение; команда disktide появится в PATH
disktide
```

`uvx disktide` запускает программу без установки. `uv tool upgrade disktide` устанавливает новую версию, а `uv tool uninstall disktide` удаляет её. Если оболочка не находит `disktide`, выполните `uv tool update-shell` (команда добавит каталог uv, обычно `~/.local/bin`, в PATH) и откройте новую оболочку.

**Через pipx:**

```bash
pipx install disktide
disktide
```

**Через pip** в уже используемом виртуальном окружении: `pip install disktide`. Многие дистрибутивы Linux и Homebrew запрещают обычную установку `pip install` в системный Python (PEP 668); `uv tool` и `pipx` создают для программы изолированное окружение.

Сканер может использовать небольшое расширение C. В PyPI оно включено в готовые пакеты для CPython 3.10–3.14 на Linux (x86_64 и aarch64, glibc и musl) и macOS (Intel и Apple silicon). В остальных случаях при наличии компилятора C оно собирается во время установки. Без компилятора установка всё равно проходит, но DiskTide использует более медленный модуль на чистом Python. Активный вариант показывает `disktide doctor`.

**Из исходного кода:**

```bash
git clone https://github.com/williamqwu/disktide && cd disktide
uv tool install .      # или: pip install .
```

После `git pull` выполните `uv tool install --reinstall .`, чтобы обновить установленную версию. О пересборке расширения C после его изменения см. [раздел об расширении в рабочей копии](docs/contributing.ru.md#rasshirenie-v-rabochey-kopii).

### Дополнительные компоненты

| Дополнение | Установка | Результат |
|---|---|---|
| `watch` | `uv tool install 'disktide[watch]'` / `pip install 'disktide[watch]'` | Только Linux. Устанавливает `inotify-simple`, чтобы монитор реагировал на события файловой системы. Без него монитор работает по таймеру. |

`disktide doctor` сообщает используемый механизм наблюдения и его состояние.

## Быстрый старт

```bash
disktide                                # интерактивный TUI, приветственный экран
disktide ~/projects                     # TUI сразу открывает указанный путь
disktide scan ~/projects                # однократное сканирование
disktide monitor list                   # список мониторов
disktide compare --since 7d ~/projects  # изменения за последнюю неделю
disktide cleanup ~/projects             # просмотр кандидатов на очистку
```

`?` открывает список клавиш текущего экрана, `,` — настройки, а Ctrl+P ищет команды по названию. Флаг `--help` работает на каждом уровне. Подробности — в [руководстве пользователя](docs/user-guide.ru.md).

## Хранимые данные

| Расположение | Содержимое | Размер |
|---|---|---|
| `~/.config/disktide/config.toml` | Настройки и недавние пути. | Меньше 1 КиБ (несколько сотен байт). |
| `~/.config/disktide/cleanup-rules/*.toml` | Пользовательские наборы правил очистки. Шесть встроенных наборов входят в пакет и сюда не копируются. | Пусто, пока вы не добавите набор; один занимает несколько КиБ. |
| `~/.local/share/disktide/data.db` | Мониторы, снимки, правила хранения и история оповещений, планы очистки (SQLite). | Пустая база — около 210 КиБ. Первый снимок дерева занимает примерно 200–500 байт на файл или каталог, в основном из-за текста путей: 11 МиБ для дерева из 23 000 элементов с длинными путями и несколько сотен МиБ для миллиона элементов. Последующие снимки того же дерева хранят только изменения — около 100 байт на изменённый элемент — и полную базовую точку объёмом около 55 байт на элемент в каждом 50-м снимке. |
| `~/.local/share/disktide/data.db.pre-vN.bak` | Однократная резервная копия перед миграцией схемы. Её имя показывает `disktide doctor`. | Размер базы на момент копирования. После запуска новой версии копию можно удалить. |
| `.disktide-quarantine/` рядом с очищаемым путём | Место, куда очистка перемещает файлы, если системная корзина недоступна на этой файловой системе. Обычно используется стандартная корзина XDG `~/.local/share/Trash`. | Зависит от перемещённых файлов. По умолчанию хранится 7 дней, максимум 10 ГиБ (`quarantine_retention_days` и `quarantine_max_bytes` в секции `[cleanup]`). |

Пути учитывают `XDG_CONFIG_HOME` и `XDG_DATA_HOME`. При первом запуске автоматически подхватываются старые каталоги `sizetrail` и `fsmonitor-cli`.
